# Steer — local iPhone journal
Preserve the simple approved white/slate-blue interface. Target iPhone 17 Pro Max, with readable layouts on other sizes.
All journal entries, notes, settings, and backups remain on the user's device. No account, API, analytics, telemetry, remote fonts, or cloud data sync. GitHub Pages serves only static code and illustrations.
Choice flow: situation → encouragement → choose → review and explicitly save → local save confirmation. Never claim saved before an IndexedDB transaction completes. Keep unsaved input visible on error. Validate backup imports and merge without silently overwriting existing entries.
Weekly periods start Monday, using device time. Report logged decisions rather than inferred behavior. Both choices count; use supportive language.
Do not use Codex's built-in browser for routine inspection; the user checks visuals in external Safari or Chrome. Verify builds, storage, and offline packaging with non-browser checks.
Do not publish journal backups or browser database contents to GitHub. Do not change the older Sites app or erase its data as part of this separate static build.
